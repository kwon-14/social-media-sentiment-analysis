# social-media-sentiment-analysis
跨学科项目：面向传播学研究的社交媒体情感分析

## 项目介绍
本项目结合软件工程技术与传媒研究，搭建社交媒体舆情情感分析简易平台。
依托Python实现文本情感识别、数据可视化，适用于综艺宣传、网络舆论、粉丝舆情等传媒场景。
可辅助内容宣传工作，快速观测大众情绪倾向，实现技术与传媒行业的融合。

## 技术栈
Python、SnowNLP情感分析、数据可视化
